## [0.6.8] - 2026-10-29

### Fixed
- Android: явно указана неигровая категория `productivity`, чтобы снизить риск ошибочной классификации приложения как игры.
- Xiaomi/POCO: добавлен адресный запрос высокой частоты в PowerKeeper только для собственного пакета приложения. Он повторяется при возврате в приложение и позволяет перекрыть сохранённый игровой лимит без ADB, очистки данных или изменения общего списка игр.

### Known limitations
- Интерфейс PowerKeeper зависит от прошивки HyperOS. Если запрос недоступен или запрещён, приложение сохраняет стандартный Android-запрос частоты; высокая частота не гарантируется на всех устройствах и при системных ограничениях.

## [0.6.7] - 2026-10-29

### Fixed
- Android: приложение явно запрашивает максимальную поддерживаемую частоту обновления при текущем разрешении экрана. Запрос восстанавливается после возврата в приложение и пересоздания Flutter surface, снимается при потере фокуса и уходе в фон; окончательный выбор частоты остаётся за системой.

## [0.6.6] - 2026-10-29

### Added
- «Подборка» / Discover вместо вкладки поиска: горизонтальные полки Cloudflare, GitHub Engineering и RFC, поиск по выбранным источникам и переход к источнику по всей строке заголовка. Карусели прокручиваются до краёв рабочей области и поддерживают управление кнопками и клавиатурой на desktop.
- Отдельный каталог источников с поиском, группами, переключателями, фильтром выбранных и изменением порядка; один сохранённый выбор управляет подборкой и поиском, прежний книжный источник переносится.
- Чтение и офлайн-сохранение полных статей и RFC через существующий EPUB-ридер: локальные изображения, оглавление, таблицы, код, исходная ссылка и метаданные. Поиск блогов ограничен недавними публикациями; RFC доступны через полный официальный индекс.
- Локальный кэш лент с датой обновления и показом сохранённой выдачи при недоступности источника; настройки и новые экраны поддерживают русский/английский, обе темы и крупный текст.
- Поиск книг: редактируемый список зеркал Z-Library с сохранением порядка и получением предложений из официального `/access-info`; новые адреса включаются только после просмотра и сохранения. Один список используется для поиска, входа и скачивания.
- Anna’s Archive: локальный клиент текущей выдачи и настройка законно полученной браузерной сессии Cookie/User-Agent, привязанной к одному официальному домену; добавлены действия доступа из настроек, страницы источника и ошибки поиска.

### Changed
- Открытая для чтения публикация не появляется в библиотеке до явного сохранения; сохранение использует ту же неизменяемую копию с прежними прогрессом и пометками. Миграция БД v3 → v4 сохраняет существующую библиотеку.
- Удалены прежние переключатели Anna’s Archive / Z-Library / Both и устаревшее состояние экрана поиска; книжные каталоги используют общий выбор источников и сохраняют фильтры, сортировку, скачивание и отмену.
- Неисправная сторонняя обёртка Anna’s Archive удалена вместе с неиспользуемыми зависимостями; поиск учитывает текущие карточки, отложенную HTML-выдачу и опубликованные источником ссылки скачивания.
- Z-Library использует ограниченные переходы между разрешёнными зеркалами, origin-scoped cookies и обновлённый протокол публичной проверки браузера; вычисление проверки не блокирует UI. Cookies не пересылаются на посторонние download/CDN-адреса.
- macOS: минимальная заявленная версия повышена до 11.0 в соответствии с deployment target готового PDFium; приложение и pods используют согласованный нижний порог.

### Fixed
- Библиотека: повторная загрузка после сохранения статьи больше не переинициализирует `late final _repository` и не вызывает `LateInitializationError`; существующие книги сохраняются при повторных обновлениях провайдера.
- SOCKS5: устранён дополнительный HTTP CONNECT из унаследованных настроек HTTP-прокси; прямое соединение и SOCKS используют явные настройки Lira, без отключения проверки TLS.
- Поиск: ошибки источника и проверки браузера не подменяются пустой выдачей; длинные сообщения прокручиваются без переполнения и предлагают перейти к настройке доступа или зеркал.

### Known limitations
- Anna’s Archive может требовать действующую браузерную сессию для того же домена, выходного IP и User-Agent. Проверка DDoS-Guard на стороне сайта, включая HTTP 403 для некоторых прокси, не отменяется сменой зеркала; такие ответы показываются как ошибка доступа, а не пустая выдача.

## [0.6.4] - 2026-10-27

### Added
- Reader: выбор 11 локальных шрифтов с кириллицей и латиницей — Inter, Lora, Literata, Source Serif 4, PT Serif, Noto Serif, Merriweather, Roboto Slab, PT Sans, Noto Sans и Roboto; добавлены курсивные варианты и лицензии.

### Changed
- Reader: на Android системные панели скрываются вместе с панелями ридера и возвращаются по тапу, при ошибке загрузки и выходе; режим учитывает возврат из фона и клавиатуру и не требует отключать edge-to-edge.
- Reader: текущая закладка EPUB остаётся активной в пределах ±400 символов одной главы, PDF — в пределах страницы; точное место перехода сохраняется, повторное нажатие удаляет исходную закладку.
- Reader: регуляторы получили видимые подписи и значения; боковые поля на десктопах/больших планшетах расширены до 240 px, на телефонах сохранены 8–64 px.
- PDF: стандартная область чтения центрируется и ограничена 800 logical px на широких окнах, без ограничения ручного увеличения; узкие окна используют доступную ширину.

### Fixed
- EPUB: восстановлены названия глав и подглав в оглавлениях с кириллическими и смешанными URI-якорями, включая «Простую экономику»; пустая или непригодная EPUB3 nav-навигация больше не блокирует NCX.
- EPUB: размер шрифта и межстрочный интервал читателя больше не перекрываются CSS книги; настройки одинаково действуют в прокрутке, горизонтальном режиме и развороте.
- EPUB: смена типографики и полей сохраняет точное место без промежуточного показа обложки; поля обеих страниц и пагинация используют общую геометрию и безопасное ограничение на узких окнах.
- PDF: исправлена прокрутка трекпадом над выделяемым текстом на macOS, сохранён pinch zoom; колесо работает также над боковыми полями без двойной обработки событий.

## [0.6.3] - 2026-10-28

### Added
- Reader: добавлены локальные закладки EPUB/PDF, кнопка текущего места и отдельные вкладки «Выделения» / «Закладки» с переходом и удалением; миграция БД сохраняет существующие книги, прогресс и заметки.

- Reader: клавиатура диалога заметки больше не меняет размер книги и не запускает скачок позиции при открытии/закрытии редактора.
- Reader: верхняя и нижняя панели плавно скрываются обратной анимацией на собственную высоту вместо мгновенного ухода за экран.

## [0.6.2] - 2026-10-27

### Changed
- EPUB: добавлено перелистывание с изгибом листа, тенями и привязкой к пальцу; развороты перелистываются вокруг корешка, короткие жесты возвращают страницу, системное уменьшение анимации учитывается.
- Уменьшены отступы во всём интерфейсе: основные поля 12 px, промежутки между карточками 12 px, между секциями 16 px; уплотнены формы, настройки, навигация и панели ридера без изменения пользовательских полей чтения.
- Карточки библиотеки и поиска получили обложки на всю ширину без внутренних полей сверху и по бокам; результаты поиска отображаются адаптивной сеткой с сохранением прогресса и отмены загрузки.

## [0.6.0] - 2026-10-24

### Added
- Единая дизайн-система: тёплая светлая тема по палитре Anthropic/Claude, графитовая тёмная тема, локальные Inter/Lora и общие UI-компоненты.
- Общая политика анимаций, диалогов и sheets с поддержкой reduced motion; новые профили чтения начинают с тёплой бумаги без изменения сохранённых настроек.

### Fixed
- EPUB: восстановлены SVG-обложки, inline-картинки и локальные ресурсы SVG; полные URI-пути больше не подменяются совпавшим basename.
- EPUB: сохранены вложенные списки, отдельные абзацы цитат и явные переносы; исправлены маркеры `<ul>` и нумерация `<ol>`.
- EPUB: таблицы отображаются сеткой с объединёнными ячейками, пагинацией и выделением; высокая строка прокручивается с сохранением позиции.
- EPUB: применяются локальные CSS-классы заголовков и сносок, cascade и скрытие элементов; выбор шрифта читателя сохраняется.

### Changed
- Библиотека, поиск, сведения о книге, вход, настройки и панели ридера приведены к общей типографике, поверхностям, отступам и semantic colors.
- Навигация адаптируется между боковой панелью и нижними вкладками, сохраняя состояние экранов; убраны glass/blur, цветное свечение и старые overlay-отступы.
- Формы, карточки, фильтры и панели адаптированы к узкому окну и крупному тексту; дополнены русские/английские подписи и accessibility labels.

## [0.5.2] - 2026-10-23

### Fixed
- EPUB: восстановлены все документы в порядке OPF spine независимо от оглавления и имени файла; повреждённый spine больше не даёт частично успешную книгу.
- EPUB: добавлено корректное чтение UTF-16 LE/BE; повреждённые текстовые последовательности не заменяются молча.
- EPUB: позиция привязана к тексту и сохраняется при reflow, смене режима, шрифта, отступов и размера окна; переход на правую страницу разворота не сохраняет предыдущую главу.
- EPUB: пересекающиеся highlights больше не дублируют текст; исправлены внутренние ссылки, fragments, encoded paths и Unicode hit-testing.
- PDF: подключены панели, оглавление, native selection, сохранённые highlights и переход к их геометрии; controller не теряется после rebuild.
- PDF: single tap не конфликтует с double-click selection, drag и long-press; native deselection очищает действия Lira.
- PDF: исправлен upstream zero-area bug для абсолютно горизонтального выделения; нормализуются только активные edges, без подмены native текста или сохранённой геометрии.
- PDF: переход к сохранённому выделению сохраняет текущий zoom, если диапазон помещается во viewport, вместо увеличения одной фразы на весь экран.
- Reader: устранена потеря новой позиции при медленной предыдущей записи; close/suspend выполняют flush, а одновременные Back не закрывают предыдущий route.
- Reader: повреждённые файлы показывают ошибку загрузки вместо подставной error-книги; выделение очищается после успешного сохранения.
- CI: исправлены несовместимая версия Flutter и игнорирование выбранного debug/release режима.
- Android: release больше не подменяет постоянный signing key debug-ключом; CI восстанавливает keystore из secrets без вывода паролей.
- Android CI: APK и AAB разделены на независимые runners после исчерпания диска при последовательной упаковке в одном job; готовый APK больше не теряется при ошибке AAB.

### Changed
- EPUB renderer окончательно переведён на native Flutter: удалены старый WebView, одноразовый patch script и неиспользуемые зависимости.
- Новые EPUB-позиции используют versioned `v:2` offsets; legacy JSON остаётся читаемым без миграции схемы БД.
- Добавлены reader-регрессии, включая настоящий PDFium; обновлены `READER.md` и документация пакетов.
- GitHub Actions закреплён на Flutter 3.41.6; CI на push/PR и перед сборками запускает reader-регрессии с настоящим PDFium.
- Релизный pipeline собирает Android, iOS, Windows, Linux и macOS; iOS IPA предназначен для самостоятельной подписи, AAB создаётся только в release, неподдерживаемый Web исключён.
- Push тега `v*` автоматически публикует единый GitHub Release, не черновик, только после успеха всех платформ; signing files удаляются после Android-сборок.
- Описание GitHub Release берётся из раздела `CHANGELOG.md` с версией тега вместо списка коммитов; отсутствующий, пустой или дублирующийся раздел блокирует публикацию.
